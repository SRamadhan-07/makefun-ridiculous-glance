A Python program — standard library only, no network — that writes one sentence to /output/entry.txt: a startup pitch that is ridiculous at first glance and real by the second, selling silence by the soundproof room hour. The sentence is 150 characters, inside the competition's gate of 1 to 200 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
